# مساعد المعلم — Teacher Assistant

منصة ويب ذكية لمساعدة معلمي المدارس في منطقة الخليج العربي على توليد خطط الدروس اليومية وأوراق العمل تلقائياً وفق النماذج الوزارية المعتمدة، باستخدام Claude AI.

## المميزات

- **توليد خطط الدروس**: توليد خطط درس يومية بنقرة واحدة وفق المنهج المختار، مع دعم JSON Schema صارم لضمان جودة المخرجات.
- **توليد أوراق العمل**: أوراق عمل متكاملة مع مفتاح الإجابات، قابلة للتصدير بصيغة Word و PDF.
- **التصدير الوزاري**: تصدير خطط الدروس إلى Word باستخدام `docxtemplater` مع قالب وزاري رسمي، وتحويلها إلى PDF عبر LibreOffice.
- **نظام الاشتراكات**: 5 خطط مجانية لكل معلم جديد، مع باقات اشتراك مدفوعة (شهرية/فصلية/سنوية).
- **نظام الإحالات**: مكافأة المعلم بفصل مجاني عند إحالة 5 معلمين يدفعون اشتراكاً.
- **دعم RTL**: واجهة عربية كاملة من اليمين إلى اليسار مع خط Tajawal.
- **لوحة مدير**: إدارة الدول، المدارس، المناهج، والدروس.

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| React 19 + TypeScript | الواجهة الأمامية |
| TailwindCSS 4 | التصميم |
| Express 4 + tRPC 11 | الخادم و API |
| Drizzle ORM + MySQL/TiDB | قاعدة البيانات |
| Claude API (عبر Manus Forge) | توليد الخطط وأوراق العمل |
| docxtemplater + Pizzip | تصدير Word |
| LibreOffice headless | تحويل PDF |
| S3 (عبر Manus) | تخزين القوالب والملفات |
| Vitest | الاختبارات |

## هيكل المشروع

```
client/
  src/
    pages/          ← صفحات التطبيق (Home, GeneratePlan, Subscription, Admin, ...)
    components/     ← مكونات UI القابلة لإعادة الاستخدام
    lib/            ← إعدادات tRPC والأدوات
server/
  _core/           ← البنية التحتية (OAuth, LLM, Storage, ...)
  db.ts            ← استعلامات قاعدة البيانات
  routers.ts       ← tRPC procedures الرئيسية
  exportDoc.ts     ← وحدة تصدير Word و PDF
  templates/       ← قوالب Word الوزارية
drizzle/
  schema.ts        ← مخطط قاعدة البيانات (21 جدولاً)
shared/
  types.ts         ← الأنواع المشتركة
  const.ts         ← الثوابت المشتركة
```

## ملاحظات مهمة

- **النموذج التجريبي**: المنصة حالياً تعتمد على Manus للبنية التحتية (OAuth, LLM, Storage, Hosting). للإطلاق التجاري، يُنصح بنقل الكود إلى خادم مستقل مع مفتاح Anthropic مباشر.
- **القالب الوزاري**: القالب الحالي مصمم بدون نموذج رسمي. يجب استبداله بالقالب الرسمي المعتمد من وزارتك.
- **بوابات الدفع**: هيكل MyFatoorah و Tap جاهز لكن يتطلب مفاتيح API لتفعيل الدفع الفعلي.
- **بيانات المنهج**: بيانات كيمياء الصف الثامن مولّدة بالذكاء الاصطناعي وتحتاج مطابقة يدوية مع الكتاب الرسمي.
