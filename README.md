# TeachAssist — مساعد المعلم

منصة عربية لمساعدة المعلمين على اختيار المنهج، وتوليد خطط الدروس وأوراق العمل، ومراجعتها وتصديرها. تستخدم React وTypeScript وExpress/tRPC وDrizzle مع MySQL، وتدعم Anthropic مباشرة وتخزين الملفات في Cloudflare R2.

**النسخة قيد الاستكمال، وليست إطلاقاً تجارياً مكتملًا.** نشر الخادم لا يثبت جاهزية تسجيل الدخول والبريد والكتب والتوليد والتصدير والدفع. الحالة الحالية وخطوات القبول موثقة في [docs/COMPLETION_STATUS.md](docs/COMPLETION_STATUS.md).

## الوظائف الموجودة في الكود

- واجهة عربية RTL لاختيار الدولة والصف والمادة والكتاب والدرس.
- فهرسة الكتب من Google Drive، ومراجعة الفهارس واعتمادها من لوحة المدير.
- توليد الخطط وأوراق العمل مع التحقق من بنية المخرجات وملكية المحتوى.
- رصيد مجاني أولي: خطتان للحساب الجديد، مع حجز ذري للرصيد قبل توليد الخطة.
- تنزيل Word مباشر للخطة وورقة العمل، وتحويلهما إلى PDF عند توفر LibreOffice على الخادم.
- معاينة HTML آمنة للطباعة عند تعذر تحويل PDF؛ ليست ملف PDF مولداً.
- مصادقة مستقلة بالبريد وOTP خلف مفتاح تفعيل، مع إبقاء مسار Manus القديم خلال الانتقال.
- سجل الخطط وأوراق العمل، والموارد التربوية، وإدارة المناهج.

الدفع مغلق: قائمة مزودي الدفع المعتمدين في الكود فارغة؛ حتى `PAYMENTS_ENABLED=true` لا يفتح شراءً أو يمنح رصيداً. MyFatoorah وTap وLemon Squeezy تحتاج مراجعة التكامل واختبارات Sandbox واعتماد حساب التاجر قبل إضافة أي مزود. PR الدفع #3 يبقى منفصلاً وDraft.

## التطوير والتحقق

المتطلبات: Node.js 22، وpnpm 10.4.1، وقاعدة MySQL للتطوير. PDF يحتاج LibreOffice؛ استخراج نص الكتب يحتاج `pdftotext`.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

```bash
pnpm check
pnpm test
pnpm build
```

سير GitHub Actions في `.github/workflows/ci.yml` ينفذ التثبيت المقفل، وفحص TypeScript، وترحيلات المخطط المتتبعة، واختبارات الوحدة والمصادقة التكاملية، والبناء. قاعدة MySQL 8 في CI مؤقتة واسمها `teachassist_test`. لا يتصل سير العمل بقاعدة الإنتاج ولا ينشر التطبيق.

لتشغيل تحقق الترحيلات واختبارات المصادقة على قاعدة اختبار محلية قابلة للمسح:

```bash
AUTH_TEST_DATABASE_URL='mysql://test_user:test_password@127.0.0.1:3306/teachassist_test' node scripts/check-test-migrations.mjs
AUTH_TEST_DATABASE_URL='mysql://test_user:test_password@127.0.0.1:3306/teachassist_test' pnpm test
```

هذه الأوامر مخصصة لقاعدة الاختبار فقط. تتحقق الأدوات من المضيف المحلي واسم `teachassist_test` قبل الاتصال، وقد تمسح الاختبارات بيانات جداولها. الاختبارات التكاملية تُتجاوز محلياً عند عدم وجود `AUTH_TEST_DATABASE_URL`؛ نجاح الاختبارات المحلية وحده لا يعني أنها شُغلت على MySQL.

## متغيرات البيئة

| المجموعة | المتغيرات | الغرض |
|---|---|---|
| الخادم | `DATABASE_URL`, `NODE_ENV`, `APP_BASE_URL` | قاعدة التطبيق ورابطه العام |
| المصادقة المستقلة | `AUTH_OTP_ENABLED`, `AUTH_OTP_SECRET`, `RESEND_API_KEY`, `FROM_EMAIL` | تفعيل OTP وإرسال البريد؛ التفعيل الحرفي `true` بعد قبول Staging فقط |
| المصادقة القديمة | `JWT_SECRET`, `VITE_APP_ID`, `OAUTH_SERVER_URL`, `VITE_OAUTH_PORTAL_URL` | دعم Manus أثناء الانتقال؛ `JWT_SECRET` بديل لمفتاح OTP عند عدم تخصيص مفتاح مستقل |
| التوليد | `ANTHROPIC_API_KEY` | الاتصال المباشر بـAnthropic |
| بديل التوليد القديم | `BUILT_IN_FORGE_API_URL`, `BUILT_IN_FORGE_API_KEY` | Manus Forge عند استخدامه بدلاً من المفتاح المباشر |
| الكتب | `GOOGLE_DRIVE_API_KEY`, `GOOGLE_SERVICE_ACCOUNT_JSON` | الوصول إلى مصادر المناهج بحسب طريقة التكامل |
| التخزين الاختياري | `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET`, `R2_PUBLIC_BASE_URL` | القوالب أو الملفات المخزنة؛ تنزيل المحتوى بالقالب المدمج لا يتطلب R2، والرابط العام اختياري |
| الدفع | `PAYMENTS_ENABLED=false` | يبقى مغلقاً إلى حين مراجعة مزود فعلي |
| الاختبارات فقط | `AUTH_TEST_DATABASE_URL` | MySQL محلي مؤقت؛ لا يُستخدم كإعداد تطبيق أو إنتاج |

استخدم مفتاح OTP عشوائياً لا يقل عن 32 حرفاً، ونطاق إرسال موثقاً لدى Resend، ورابط `APP_BASE_URL` مطابقاً للنطاق الذي يستخدمه المعلم. اترك `AUTH_OTP_ENABLED=false` حتى تطبيق الترحيل المتتبع واختبار البريد والجلسات على Staging.

## ملاحظات النشر

- ترحيل المصادقة المتتبع هو `drizzle/0003_independent_auth.sql`. لا يُطبّق تلقائياً عند تشغيل الخادم.
- ملفات SQL القديمة في `drizzle/migrations/` ليست سجل ترحيلات Drizzle المتتبع، ولا تُطبّق كبديل لهذا الترحيل.
- مواصفات المصادقة السابقة في `docs/AUTH_SPEC*.md` وثائق تصميم تاريخية؛ الحالة الفعلية في `docs/COMPLETION_STATUS.md` والكود الحالي.
- القالب المدمج قالب عربي عام؛ يجب مراجعة مطابقته للنموذج الوزاري الفعلي قبل وصفه بأنه معتمد.
- الكتب والفهارس يجب مطابقتها مع الإصدار الرسمي للصف والمنهج المطلوب.
